# 🎅 Тайный Санта Telegram Bot

Telegram бот для организации игры "Тайный Санта" с полной автоматизацией распределения подарков.

`

## 🚀 Быстрый старт
### Создание виртуального окружения
```bash
python -m venv .venv
```
Виртуальное окружение активируйте самостоятельно, либо через среду разработки
### Создайте папку data в корне проекта
### Установка зависимостей
```bash
pip install -r requirements.txt
```

### Сгенерируйте токен через @BotFather
Файл pattern.env переименуйте в .env и вставьте на место "your_token_here" ваш токен


### **Запустите бота для проверки:**
```bash
python bot.py
```
