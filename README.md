# 🎅 Тайный Санта Telegram Bot

Telegram бот для организации игры "Тайный Санта" с полной автоматизацией распределения подарков.


## 🚀 Быстрый старт
### Создание виртуального окружения
```bash
python -m venv .venv
```
Виртуальное окружение активируйте самостоятельно, либо через среду разработки
### Создайте папку data в корне проекта
### Установка зависимостей
```bash
pip install -r requirements.txt
```

### Сгенерируйте токен через @BotFather
Файл pattern.env переименуйте в .env и вставьте на место "your_token_here" ваш токен


### **Запустите бота для проверки:**
```bash
python bot.py
```

# Обновления для РФ
В связи с блокировками Telegram, для запуска бота нужно реализовать прокси-подключение из файла bot.py. Как это сделано у меня в функции main:

```python
PROXY_URL = "http://127.0.0.1:10809" # рабочий порт proxy

        # Создание приложения с прокси
        application = (
            Application.builder()
            .token(BOT_TOKEN)
            .proxy(PROXY_URL)  # Прокси для отправки сообщений
            .get_updates_proxy(PROXY_URL)  # Прокси для получения обновлений (polling)
            .build()
        )
```
